Setup Java 11 su Ubuntu 24

Per impostare Java 11 come defaut: 

 1) nano ~/.bashrc (aprire/creare il file con un editor es. vim)

 2) export PATH=/usr/lib/jvm/java-11-openjdk-amd64/bin:$PATH (inserire la linea di import)

 3) Salvare e controllare che la versione di java sia giusta con il comando java --version
